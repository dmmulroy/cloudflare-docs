# Cloudflare Docs Artifacts Search Proof

Screen recordings and extracted result lists for the Artifacts docs search visibility fix.

- `artifacts-search-before.gif`: inline preview of production `developers.cloudflare.com` before the change.
- `artifacts-search-after.gif`: inline preview of the local docs build after the change.
- `artifacts-search-before.mp4`: production `developers.cloudflare.com` before the change. The rendered top 10 results for `Artifacts` do not include `/artifacts/`.
- `artifacts-search-after.mp4`: local docs build after the change. The rendered top 15 results for `Artifacts` include `/artifacts/` at position 13.
- `artifacts-search-before.webm` and `artifacts-search-after.webm`: original Playwright recordings.
- `artifacts-search-before.json` and `artifacts-search-after.json`: extracted result lists used to verify the recordings.
