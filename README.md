Screen recordings and extracted result lists for the Artifacts docs search visibility fix.

- `artifacts-search-before.webm`: production `developers.cloudflare.com` before the change. The rendered top 10 results for `Artifacts` do not include `/artifacts/`.
- `artifacts-search-after.webm`: local docs build after the change. The rendered top 15 results for `Artifacts` include `/artifacts/` at position 13.
- `artifacts-search-before.json` and `artifacts-search-after.json`: extracted result lists used to verify the recordings.
